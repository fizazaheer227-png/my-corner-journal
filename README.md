# 📔 My Corner – Personal Digital Journal

My Corner is a personal digital journaling application designed to provide users with a private, creative, and scrapbook-inspired space to record their thoughts, moods, memories, goals, and everyday moments.

## ✨ About the Project

My Corner combines traditional journaling with a modern digital experience. The interface is inspired by physical journals, scrapbooks, handwritten notes, paper textures, and personal diaries.

The goal is to make digital journaling feel more personal, expressive, and enjoyable rather than like a conventional notes or productivity application.

## 🌷 Features

- Personal everyday journal
- Mood tracking
- People & memories section
- Memory Jar & Vault
- Dreams & Horizons
- Wishlist
- Vision Board
- Future Me journal
- Gratitude section
- Habit Garden
- Period tracker
- Doodle Book
- Collections
- Search functionality
- Private journal features
- Scrapbook-inspired interface
- Interactive journal navigation
- Mobile-friendly design

## 🛠️ Technologies Used

- Kotlin
- Jetpack Compose
- Android
- Gradle
- Git & GitHub
- Google AI Studio

## 🎯 Project Objective

The objective of My Corner is to create a digital space where users can document different parts of their lives in one place while maintaining the emotional and creative feeling of a physical journal.
